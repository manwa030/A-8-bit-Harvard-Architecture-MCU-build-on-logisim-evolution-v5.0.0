直接寫 Assembly（ASM 模式）

        
右上角切到 ASM，編輯器就是純組合語言。按「編譯」會組譯成 32-bit 指令；按「執行」或「單步」直接在模擬器跑。右側「符號表」會列出每個 label 的位址與該位址的指令 word。

        
語法

        
    
          
  • 每行：[label:] mnemonic operands；; 或 # 後面是註解。
    • 
          
  • 暫存器：r0–r7；r0 恆為 0。
    • 
          
  • 立即值：10、0x1F、-1（8-bit 會自動取補數）。
    • 
          
  • 記憶體：lw r1, 16(r0)、sw r1, 0(r3)；位址是 (rs + imm) & 255。
    • 
          
  • 標籤可單獨一行，或寫成 loop: add r1, r1, r2。
    • 
          
  • 分支／跳躍都寫標籤；assembler 自動算 b<cond> 的相對 offset，j／call 用絕對位址。
    • 
          
  • 目前不支援 .org／.equ／資料段；常數請用 li。
    • 
        

        
常用指令

        

          
寫法意義

          
li r1, 5r1 ← 5

          
mv r1, r2r1 ← r2；編成 addi r1, r2, 0

          
add r1, r2, r3r1 ← r2 + r3（sub/and/or/xor 同理）

          
addi r1, r2, 1r1 ← r2 + 1（andi/ori/xori 同理）

          
slli r1, r1, 1邏輯左移；srli／srai 同理

          
lw r1, 16(r0)r1 ← RAM[16]

          
sw r1, 16(r0)RAM[16] ← r1

          
beq r1, r2, label相等時相對分支（bne/blt/bge/bgt/ble，加 u 為無號）

          
j label / call label / ret絕對跳躍／呼叫／返回

          
nop / halt空指令／停止（硬體不一定停，建議 j self）

        

        
最小範例

        
        li   r1, 0
        li   r2, 1
        li   r3, 6
loop:   blt  r2, r3, body
        j    done
body:   add  r1, r1, r2
        addi r2, r2, 1
        j    loop
done:   sw   r1, 0(r0)
end:    j    end

        
模擬器約定：寫 RAM[0xFE] 會把 byte 附加到 console；寫 RAM[0xFF] 非 0 會停止。真實 Logisim 電路沒有這個 I/O，除非另外加顯示硬體。


        
CPU8b 是什麼？

        
CPU8b 是 CPU8b.circ（Logisim 2.7.1）內的單週期、哈佛架構 8-bit CPU：指令與資料分開存放，每個時鐘週期完成一條指令。指令字寬 32 bit，資料與暫存器都是 8 bit。

        

          
項目規格

          
指令 ROM256 × 32 bit（8-bit 位址）

          
資料 RAM256 × 8 bit（8-bit 位址，separate bus）

          
暫存器r0–r7；r0 永遠為 0，r1–r7 可寫

          
PC / LINK各 8 bit；PC 指向 ROM，LINK 存 JSR 返回位址

          
ALUadd / sub / and / or / xor / sll / srl / sra，另含條件比較

          
定址lw rd, imm(rs)、sw rt, imm(rs)，位址 =(rs+imm) mod 256

        


        
指令格式（32 bit）

        

          
bits31:2928:2625:2322:2019:1716:1413:65:32:0

          
欄位rdrsrtshamtfunctcondimm8PCopopcode

        


        
opcode

        

          
op指令類別行為

          
000ALU regrd = rs funct rt（無號）

          
001ALU immrd = rs funct imm8

          
010shift logicalrd = rs <</>> shamt

          
011lird = imm8

          
100lwrd = RAM[(rs+imm8)&255]

          
101swRAM[(rs+imm8)&255] = rt

          
110shift arithmetic / signedsra；有號比較與分支

          
111halt停止（實際電路若不停，請用 j self）

        


        
funct（ALU）

        
01234567

        
addsubandorxorsllsrlsra


        
PCop（程式計數器）

        

          
PCop動作

          
000PC ← PC + 1

          
001PC ← imm8（絕對跳躍，j）

          
010條件成立：PC ← PC + sign_extend(imm8)（相對分支）

          
011PC ← LINK（ret）

          
100LINK ← PC + 1；PC ← imm8（call）

        

        
重要：分支的 imm8 是「相對目前 PC 的位移」，不是絕對位址；j 與 call 的 imm8 才是絕對位址。編譯器已自動換算。


        
cond

        
012345

        
eqneltgegtle

        
有號／無號由 opcode 決定：110 有號（blt 等），000 無號（bltu 等）。


        
C8 語言

        
C8 是為這顆 CPU 設計的小型 C 子集，編譯成 32-bit 指令後可直接放入 ROM。

        
支援

        
    
          
  • 全域變數與一維陣列：int x;、int a[8] = {1,2,3};、byte b;
    • 
          
  • 運算子：+ - * / % & | ^ ~ ! << >> < <= > >= == != && ||、賦值與複合賦值
    • 
          
  • 控制流：if/else、while、for、do/while、break、continue、return
    • 
          
  • 輸出（模擬器慣例）：print("text")、printnum(expr)（十六進位）、putchar(expr)、exit()
    • 
          
  • void main() { ... } 或直接把語句寫在最外層
    • 
        

        
限制

        
    
          
  • 沒有函式／遞迴（hardware 只有一個 LINK 暫存器）；請用迴圈。
    • 
          
  • 位移量必須是常數 0–7；* / % 以組合語言迴圈展開，僅支援 8-bit 無號除法。
    • 
          
  • 所有變數靜態配置在 RAM 0x00–0xDF；最多 224 bytes。
    • 
          
  • 不做陣列越界檢查；程式最多 256 條指令。
    • 
          
  • int 比較採有號；byte 目前與 int 相同（保留欄位）。
    • 
        


        
記憶體約定

        

          
位址用途

          
0x00–0xDF全域變數／陣列（編譯器配置）

          
0xE0–0xED編譯器保留 scratch（目前未使用）

          
0xFE輸出埠：寫入 byte 會附加到模擬器 console

          
0xFF結束埠：寫入非 0 會停止模擬器

        

        
0xFE / 0xFF 只是模擬器與 GUI 的軟體慣例；在真實 Logisim 電路中它們仍然是一般 RAM 格子，不會有 I/O 效果。


        
放入 Logisim

        
    
          
  1. 在 CPU8b.circ 的 ROM 按右鍵 → Load Image，選 .hex。
    2. 
          
  2. ROM 的 addr/data 要是 8 32；資料格式是 v2.0 raw。
    3. 
          
  3. 按 Reset（clear）再開 clock；程式從位址 0 開始。
    4. 
          
  4. 編譯器結尾會放 j self；若你的電路 halt 不會停 PC，這是安全的結尾。
    5. 
        


        
把 HEX 寫入 .circ（2.7.1 / Evolution 5）

        
GUI 右上角的 「寫入 .circ」 可以直接把目前編譯好的 HEX 塞進電路檔的 ROM，下載一個已燒錄的 *_programmed.circ。支援 CPU8b.circ（Logisim 2.7.1）與 CPU8b_evol.circ（Logisim-evolution 5.0）。

        
    
          
  1. 先按「編譯」，確認沒有錯誤。
    2. 
          
  2. 按「寫入 .circ」，選擇你的 .circ。
    3. 
          
  3. 瀏覽器會下載 原檔名_programmed.circ；用 Logisim 打開即可。
    4. 
          
  4. 它會找第一個 32-bit ROM（addr/data: 8 32），只改 ROM 內容，其餘接線不動。
    5. 
        

        
如果電路有多個 ROM，請確認第一個 32-bit ROM 是指令 ROM；CPU8b 與 CPU8b_evol 都只有一個。


        
檔案與指令列

        
同一資料夾的 c8c.py 提供命令列版本：

        
py -3 c8c.py program.c8 --run
py -3 c8c.py program.c8 -o program.hex
py -3 c8c.py program.asm --assemble --run

        
GUI 是這個 c8studio.html 單檔；所有編譯與模擬都在瀏覽器內完成，不需要網路。
